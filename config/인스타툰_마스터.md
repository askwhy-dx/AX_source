# 인스타툰 마스터 프롬프트 *(SSOT · 2026-09-10 신설)*

**여기가 그림의 정본이다.** 장별 프롬프트는 `tools/build_toon_prompt.py` 가 이 파일에
회차 문구를 끼워 만든다 — 프롬프트를 고치려면 **코드가 아니라 이 파일**을 고친다.

원본은 사용자가 준 `config/인스타툰_제작기준.txt` 다. 그 문서의 §2 공통 마스터 프롬프트를
치환 자리(`{...}`)만 박아 옮겼다. **문장을 임의로 다듬지 않았다** — 실제로 그림이
그 문장들로 나왔기 때문이다.

## 치환 자리

| 자리 | 무엇 | 어디서 오나 |
|---|---|---|
| `{상단제목}` | 큰 한글 제목 (없으면 빈칸) | 대본 `제목` |
| `{회차표시}` | `n/12` | 장 번호 |
| `{말풍선}` | 대사 (없으면 빈칸) | 대본 `말` |
| `{화면문구}` | 노트북·모니터에 적히는 글 | 대본 `화면문구` |
| `{메모문구}` | 메모장·포스트잇에 적히는 글 | 대본 `메모문구` |
| `{장면설명}` | 이번 컷의 연출 | 대본 `장면설명` |

⚠️ 빈 자리는 **「없음」이라고 쓰지 말고 줄째로 뺀다** — 「말풍선: 없음」이라고 적으면
그 글자가 판에 박힌 사례가 이 계통 도구에서 흔하다.

## PROMPT_START

첨부한 자료를 기준으로 정사각형(1:1) 인스타툰 캐러셀 1장을 제작해줘.

첨부파일 역할:

* 첨부한 기획서 PDF는 이번 인스타툰의 원고, 장면 순서, 제목 문구, 말풍선 문구, 장면 설명의 기준이다.
* 첨부한 인스타툰 레퍼런스 이미지들은 반드시 따라야 할 화풍, 구도, 톤앤매너, 제목 배치, 회차 배지 스타일, 감정 표현, 소품 밀도의 기준이다.
* 첨부한 유삐 캐릭터 이미지는 주인공 캐릭터 디자인 기준이다. 유삐의 얼굴형, 귀, 눈, 붉은 볼, 오렌지색 상의, 사원증, 직장인 곰돌이 느낌을 유지해라.

중요:
이번 작업은 단순 카드뉴스나 템플릿 합성 이미지가 아니라,
한 컷 전체를 완성된 일러스트로 그린 고퀄리티 한국형 인스타툰이어야 한다.

반드시 지켜야 할 스타일:

* 귀엽고 따뜻한 한국형 인스타툰 느낌
* 크림색 배경
* 진한 갈색 선화
* 파스텔 오렌지 / 베이지 중심 색감
* 부드럽고 따뜻한 채색
* 여백이 많고 정돈된 한 컷 구성
* 성인 직장인이 봐도 공감되는 직장인 일상툰 느낌
* 살짝 짠하고 웃긴 감성
* 너무 유아틱하지 않고, 너무 실사풍도 아니게

반드시 지켜야 할 시리즈 통일 규칙:

* 같은 주인공 유삐 캐릭터 디자인을 유지할 것
* 상사는 **안경 쓴 회색 곰돌이**다(사람 아님). 흰 셔츠·남색 넥타이·정장. 등장하는 모든 장에서 같은 모습을 유지할 것 — 2026-09-10 회차에서 6장은 안경이 없고 8장은 있어 한 장을 다시 그렸다.
* 같은 선 굵기, 같은 배경 톤, 같은 채색 질감 유지
* 상단 제목 위치를 일관되게 유지할 것
* 우측 상단 회차 배지 위치와 스타일을 일관되게 유지할 것
* 전체적으로 같은 시리즈로 보이는 통일감을 유지할 것
* 장면마다 감정, 포즈, 소품만 달라지고 브랜드 톤은 유지할 것

화면 구성 규칙:

* 상단 중앙에 큰 한글 제목
* 우측 상단에 회차 표시 배지 "{회차표시}"
* 중앙에는 유삐 캐릭터가 업무 상황을 겪는 장면
* 책상, 노트북, 메모장, 서류, 머그컵, 모니터, 포스트잇, 간단한 사무용 소품 등으로 상황을 표현
* 장면은 단순하지만 감정과 상황은 명확하게 보여줄 것
* 텍스트는 적당히 크고 잘 읽히게 할 것
* 작은 글씨를 남발하지 말 것
* 노트북 화면, 메모장, 표, 말풍선도 모두 같은 일러스트 화풍으로 자연스럽게 그릴 것
* 화면에 AI 서비스가 나오면 **Claude 로고만** 쓸 것 — 다른 AI 서비스의 로고·아이콘은 넣지 말 것

퀄리티 기준:

* 첨부한 레퍼런스 이미지 수준의 완성도를 유지할 것
* 캐릭터를 스티커처럼 붙여 넣은 느낌이 나면 안 된다
* 표정, 손동작, 포즈, 시선, 소품 배치가 자연스러워야 한다
* 노트북 화면이나 표도 딱딱한 와이어프레임처럼 보이지 않게, 인스타툰 안에 자연스럽게 녹여라
* 카드뉴스, PPT, 업무용 안내문 같은 느낌이 아니라, 완성된 인스타툰 일러스트처럼 보여야 한다

반드시 피할 것:

* 실사풍
* 3D 렌더 느낌
* 템플릿 조립 느낌
* 스티커 붙인 듯한 캐릭터
* 단순 도형 위주의 카드뉴스 느낌
* 지나치게 많은 배경 요소
* 복잡한 구도
* 작은 글씨 남발
* 레퍼런스와 다른 캐릭터 얼굴
* 어린이용 그림책처럼 너무 유아적인 느낌
* 인스타그램 앱 화면(계정명·좋아요·댓글 아이콘)은 그리지 마라 — 판 안쪽만 그린다
* **달력·시계의 실제 날짜·연도 숫자는 그리지 마라** — 엉뚱한 연도가 박힌다(2026년 회차인데 「2024 11」이 나온 적 있다). 날짜가 필요하면 숫자 없이 동그라미 표시나 「월요일」 같은 말로만 보여라.

텍스트는 아래 내용을 정확하게 반영해줘:

이번 장면 설명:

반드시 첨부된 레퍼런스 이미지와 동일한 수준의 완성도, 동일한 인스타툰 화풍, 동일한 시리즈 감성을 유지하고, 카드뉴스나 템플릿 조립 이미지처럼 보이지 않게 한 컷 전체를 완성된 일러스트로 그려줘.

텍스트는 읽기 쉽게 선명하게 넣고, 지나치게 작은 글씨는 사용하지 마.
캐릭터 표정과 손동작이 장면 감정을 가장 잘 전달하도록 그려줘.
레퍼런스 이미지와 비교했을 때 같은 작가가 그린 시리즈처럼 보여야 한다.
