| | 실측 |
|---|---|
| **스위치만 보내면 안 된다** | 등록 `.bat` 2개만 압축해 보내면 `MODULE_NOT_FOUND` 로 죽는다. 켤 기계(코드·데이터)가 같이 가야 한다 |
| **공용 `node_modules` 의존이 안 보인다** | 제작 PC 에서는 한 층 위에서 빌려 써 잘 돌지만, 옮기면 죽는다. **옮기기 전에 `package.json` 선언을 실측으로 확인** |
| **받는 팀 몫은 번호로** | 누를 파일에 `1_` `2_` `3_` `4_` 를 붙이고 **전달본 루트에 펼친다.** 하위 폴더로 숨기면 못 찾는다 |
| **「고칠 곳」과 「도는 곳」을 갈라라** | 사본을 고치면 다음 제작본에서 사라진다. 사본 자리에서 실행하면 막는 가드를 넣는다 |
| **자격정보는 따로 생각한다** | 채널 로그인·세션 쿠키·구글 토큰이 꾸러미에 딸려 간다. 보내는 경로와 사후 삭제를 정해 둘 것. **공용 `_gdrive` 토큰은 한 사람의 Drive 전체·Gmail 권한이다** — 선물에는 용도 전용 토큰(`drive.file`)을 따로 받아 싣는다 (26.09.17) |
| **화면 공유를 GitHub Pages 로 하지 않는다** | `tes1` 은 public 리포라 「추측 불가 경로」가 무인증 API 폴더 목록에 그대로 보이고, 지워도 git 이력에서 받아진다(26.09.17 실측). 사내 데이터 화면은 **Apps Script 웹앱(접근=회사 도메인)** 으로 — 구현 예 `Book-team/apps_script/` |

| 등급 | 뜻 | 개략 규모(추정) |

| **★1** | 기존 산출물 재조합 | 3시간 이내 — **T3 선물 규격** |
| **★2** | 기존 쿼리·파이프라인 재사용 + 조립 | 1~2주 |
| **★3** | 신규 데이터원 확보 **또는** 생성물 검수 체계 필요 | 3~6주 |
| **★4** | 예측·판단 + 정확도 측정 체계가 같이 필요 | 2~3개월 |
| **★5** | 표본·권한·조직 합의가 선행 — 착수 여부부터 결정 대상 | 착수 전 별도 판단 |

**A/B/C 라우팅** (`AX_source/docs/AX확산/00_AX확산_계획.md` T7)

| | 뜻 |
|:-:|---|
| **A** | 레시피 링크 — 팀이 직접 한다 |
| **B** | 다음 클리닉(T6) 예약 — 옆에 앉아 같이 돌려본다 |
