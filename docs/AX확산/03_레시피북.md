## 쓰는 법

1. 아래에서 **내 업무와 닮은 것** 하나를 고른다
2. 「복붙할 것」을 그대로 복사해 클로드 코드에 붙인다
3. 「바꿀 곳」만 내 것으로 고친다
4. 결과가 이상하면 「안 되는 경우」를 먼저 본다

**잘 안 되면 수요일 클리닉으로 오면 된다. 옆에 앉아 같이 한 번 돌려본다.**

### 이 세 줄만 지킨다

1. **학생 개인정보(성명·연락처·주소)와 DB 계정은 프롬프트에 넣지 않는다**
2. **공용 폴더·남의 폴더에서 삭제·덮어쓰기는 하지 않는다**
3. **자동 발송(메일·문자·외부 전송)은 DX 확인 후 켠다**

## A. 문서·보고

### A1 · 긴 문서 → 3줄 요약 + 핵심 표

```
걸리던 시간  40분 → 2분   (38분 절감)
복붙할 것    이 문서를 3줄로 요약하고, 핵심 내용을 「항목 / 내용 / 근거 위치」
            3칸 표로 정리해줘.
            문서에 없는 내용은 절대 넣지 말고, 애매하면 「불명확」이라고 써.
            원문 몇 쪽에서 가져왔는지 표에 남겨줘.
바꿀 곳      없음 (문서만 바꿔 넣는다)
안 되는 경우  스캔본(이미지) PDF 는 못 읽는다
```

### A2 · 여러 문서 → 하나의 비교표

```
걸리던 시간  2시간 → 10분   (110분 절감)
복붙할 것    이 폴더의 문서들을 같은 기준으로 비교해서 표 하나로 만들어줘.
            비교 항목은 문서들에서 공통으로 나오는 것만 고르고,
            어떤 항목을 왜 골랐는지 먼저 알려준 다음 표를 만들어.
            문서에 없는 항목은 「없음」으로 두고 추측하지 마.
바꿀 곳      폴더 경로 · (원하면) 비교 항목 지정
안 되는 경우  문서 형식이 너무 다르면 공통 항목이 2~3개밖에 안 나온다
```

### A3 · 초안 형식·말투 통일

```
걸리던 시간  30분 → 3분   (27분 절감)
복붙할 것    이 초안을 예시 문서와 같은 형식·말투로 다듬어줘.
            내용은 바꾸지 말고 표현만 고쳐.
            내가 쓴 문장 중 뜻이 애매한 곳은 고치지 말고 따로 목록으로 알려줘.
바꿀 곳      예시 문서 경로
안 되는 경우  예시 문서가 짧으면 말투를 못 잡는다 (2쪽 이상 권장)
```

### B2 · 회의 전 안건 브리핑

```
            말투와 형식은 예시 파일과 똑같이 하고,

안 되는 경우  표에 빈칸이 있으면 문장이 어색해진다 → 빈칸 먼저 채운다
```

```
바꿀 곳      안내 자료 경로
안 되는 경우  자료가 옛날 것이면 틀린 답이 그럴듯하게 나온다 → 자료 날짜 먼저 확인
```

## D. 자료 정리

### D1 · 흩어진 일정 → 일정표 1장

```
걸리던 시간  1시간 → 5분   (55분 절감)
복붙할 것    이 폴더의 파일들에서 날짜가 들어간 일정을 전부 찾아
            「날짜 / 무엇 / 어디서 나왔는지」 3칸 표로 만들어줘.
            날짜순으로 정렬하고, 연도가 없으면 「연도불명」으로 표시해.
            같은 일정이 여러 번 나오면 한 줄로 합치고 몇 번 나왔는지 적어줘.
바꿀 곳      폴더 경로
안 되는 경우  「다음 주 화요일」 같은 상대 날짜는 못 잡는다
```

### D2 · 자유응답 → 유형별 분류

```
걸리던 시간  2시간 → 10분   (110분 절감)
복붙할 것    이 응답들을 비슷한 것끼리 묶어줘.
            묶음마다 「유형 이름 / 건수 / 대표 응답 2개」를 보여주고,
            어디에도 안 맞는 건 「기타」로 따로 빼줘.
            원문을 고치거나 요약하지 말고 그대로 인용해.
바꿀 곳      응답 파일 경로
안 되는 경우  응답이 30건 미만이면 묶는 의미가 없다
```

### D3 · 파일 이름·형식 정리

```
걸리던 시간  40분 → 3분   (37분 절감)
복붙할 것    이 폴더 파일들의 이름을 「YYMMDD_구분_제목」 형식으로 바꾸는
            계획을 먼저 표로 보여줘. 내가 확인하면 그때 바꿔.
            날짜를 못 찾은 파일은 바꾸지 말고 목록으로 알려줘.
바꿀 곳      폴더 경로 · 이름 규칙
안 되는 경우  같은 이름이 생기는 경우가 있다 → 계획 표에서 먼저 걸러야 한다
```

> ⚠️ **「계획을 먼저 보여줘」가 이 레시피의 핵심이다.**
> 파일 이름 변경은 되돌리기 어렵다. 바로 시키지 말고 항상 계획을 먼저 받는다.

### 현실적인 구간

| 쓰는 사람 | 월 절감 (1인) | 20명 부서 |
|---|--:|--:|
| **3건만 쓴다** | 약 1.5~2시간 | 약 30~40시간 |
| **8건 쓴다** | 약 7시간 | 약 140시간 |
| 15건 전부 | 약 14시간 | 약 280시간 |

⚠️ **위 숫자는 예상치다.** 「걸리던 시간」은 담당자 진술 기준이고 실측이 아니다.
**실제로 쓴 사람의 실측이 나오면 그 값으로 바꾼다.** 예상치를 근거로 성과를 보고하지 않는다.

⚠️ 절감시간보다 중요한 지표는 **「팀이 직접 만든 자동화 건수」**다.
DX가 만들어준 게 늘어나는 건 확산이 아니라 외주화다.

## 좋은 레시피의 조건 — 직접 만들어 올릴 때

| ✅ 레시피다 | ❌ 레시피가 아니다 |
|---|---|
| 복사·선택이 되는 **텍스트** | 스크린샷·이미지 |
| **한 가지 일**만 한다 | "AI로 업무 자동화하기" (너무 큼) |
| **어디를 바꾸는지** 적혀 있다 | 우리 폴더 구조에서만 도는 것 |
| **안 되는 경우**가 적혀 있다 | 성공했을 때 얘기만 |

**위 15건 전부에 같은 장치가 들어 있다** —
*"추측하지 마 / 없으면 빈칸으로 / 원문 그대로 / 어디서 왔는지 남겨 / 안 맞으면 멈춰."*

AI는 틀렸을 때 에러를 내지 않는다. **그럴듯한 답을 조용히 준다.**
이 한 줄을 빼면 레시피가 아니라 사고의 원인이 된다.
